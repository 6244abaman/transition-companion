# Open Aba's apps

Bookmark this public page to find the apps from a phone or another computer.
The apps run on Render; Aba's computer and coding assistants can be closed.

| App | Open and share | Owner's Render dashboard |
| --- | --- | --- |
| Transition Companion — development review | [Open Transition Companion](https://transition-companion-review.onrender.com/) | [Manage review site](https://dashboard.render.com/static/srv-dbsb37jl550s73fvm5t0) |
| Finance/Miluim — Momentum Business Rebuild (reserve app) | [Open Finance/Miluim](https://rss-app-2gwd.onrender.com/) | [Manage Finance/Miluim — rss-app](https://dashboard.render.com/static/srv-dblmkehsrm7s73f2prh0) |

**Finance/Miluim** is the reserve/business recovery app in `reserve-soldier-support`. In the **Momentum Claude** Render workspace, find its interface under **`rss-app`** and its AI backend under **`rss-proxy`**.

Opening an app needs no Render account. Managing it requires the owner's
Render login and the **Momentum Claude** workspace. There is no daily Start
step. Ordinary updates publish to these same addresses from their linked
GitHub branches.

For a manual update, open the app's dashboard and choose **Manual Deploy →
Deploy latest commit**, then wait for **Live**. Each app's repository contains
`HOSTING.txt` and `app-deployment.json` with its actual branch and settings.

The Transition Companion review build has not replaced the older GitHub Pages
app. Reviewers should use the Render review link above for the current work.
