PRIVATE MEMORY
The session is temporary until you create encrypted memory in Privacy & memory.
Use a passphrase of at least 12 characters; it cannot be recovered if forgotten.
Unlock saved memory when you return. Download an encrypted backup yourself.
Import replaces the current Next Generation memory only after password validation.
Lock before sharing the computer. Delete removes this app's local memory; backups
you downloaded must be deleted separately. Browser clearing can erase local data.
The old app's memories are not imported, changed or deleted.

OPTIONAL AI SETUP (INSTALLATION OWNER)
In next-generation, copy .env.example to .env. Set OPENAI_API_KEY,
OPENAI_MODEL (a model supporting Responses structured output), and a random
GATEWAY_ACCESS_TOKEN at least 24 characters long. Restart the app.
Enter the gateway access code in Privacy & memory, NOT your OpenAI API key.
Each request shows exactly which personal packet you approve for transmission.
Extra context starts OFF. No automatic AI calls or background sharing.
AI requires internet and provider credentials/billing. No paid resource is created
by this repository. Provider retention terms still apply. This is not public auth.

VOICE AND LINKS
Voice depends on browser support, permissions, internet and possibly its external
speech provider. A disclosure appears before each voice action. Typing always works.
Official sources and human-help links require internet; telephone links need a
calling-capable device. This app does not contact a person on your behalf.
